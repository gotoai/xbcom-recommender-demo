# 訪日外国人旅行者

XB eSIMアプリを通してXBCOM社の利用し、日本訪問中の外国人旅行者を指す。今回は実証実験対象地域を含む、東京都23区地域での訪問中の訪日外国人旅行者に絞る。

## 滞在期間

具体の日付を省略し、月曜日から日曜日の一週間期間を対象期間とする。この場合、2000人のXB eSIM該当ユーザーが東京都に滞在すると仮説する。

## 国籍分布

日本政府が過去公表した、国籍別の訪日外国客数及び宿泊数の調査結果をもとに仮説的に分布を作成。

### 算出方法

- 訪日外客数: JNTO「国籍別/月別 訪日外客数」2026年1月～4月の累計値
- 平均泊数: JNTO「訪日外国人消費動向調査」2025年 表4-1「国籍・地域(21区分)別 平均泊数」の滞在日数区分
- ある時点で滞在している旅行者数は「年間訪日客数 × 平均滞在日数」に比例するため(リトルの法則)、これを人日(person-days)として各国のシェアを求め、2,000人に按分した
- 平均滞在日数は「平均泊数 + 1日」として算出
- 平均泊数は「91日間以上1年未満」区分を除外して再計算した。当該区分は留学生・技能実習生・長期就労者が中心であり、日数ベース課金のeSIMを購入する短期旅行者とは利用実態が異なるため。除外しない場合、ベトナムの平均泊数は45.3泊(人泊の77.5%が当該区分に由来)となり、実態から乖離する

### デモ用の分布平滑化(べき乗調整)

実データの構成比は上位国に強く偏り、そのままでは少数国のサンプルが確保できずレコメンドの検証に支障が出るため、デモ用にべき乗変換で平滑化する。

1. 各国の実シェア r = 当該国の人日 / 全体の人日
2. べき乗を取る: r' = r^α (α = **0.4**)
3. r' を再正規化する: r'' = r' / Σr'
4. r'' を2,000人に按分する(端数は最大剰余方式)

α = 1.0 で実データどおり、α を小さくするほど均等分布に近づく。α = 0.4 では上位4か国の合計シェアが 54.7% から 27.1% に下がり、全36市場が7人以上を確保できる(α = 1.0 ではクウェート・カタール・オマーン・バーレーンが0人となる)。

| α | 上位4か国シェア | 最小市場の人数 | 0人の市場数 |
| ---: | ---: | ---: | ---: |
| 1.0 (実データ) | 54.7% | 0 | 4 |
| 0.5 | 31.8% | 4 | 0 |
| **0.4 (採用)** | **27.1%** | **7** | **0** |
| 0.3 | 22.8% | 12 | 0 |

### 注記・前提

- 上記は日本全国の訪日客数を基準としており、国籍別の東京訪問率の差は反映していない。実際には韓国・台湾は九州・関西の訪問比率が高く、東京都に限れば構成比はやや下振れする可能性がある
- 基準期間を2026年1月～4月としているため、春節(2月)および桜シーズン(3月～4月)の需要を含み、夏季・秋季の需要は含まない。通年平均とは構成比が異なる
- 中国は2025年同期(1月～4月)比で **-55.1%** と大きく減少している(3,130,450人 → 1,404,492人)一方、韓国は +22.0%、台湾は +24.2% と増加し、総数はほぼ横ばい(-0.5%)である。このため2025年通年を基準とした場合と比べ、中国の構成比が大きく下がり、韓国・台湾が上位となる
- 訪日外客数は2026年1月～4月、平均泊数は2025年(暦年)の値であり、基準年次が異なる。消費動向調査の2026年通年値が未公表であるため
- JNTO統計では湾岸6か国が「GCC6か国」(2026年1月～4月累計 8,577人)として合算公表されているため、サウジアラビア・アラブ首長国連邦・クウェート・カタール・オマーン・バーレーンへの内訳は人口規模および海外渡航傾向に基づく仮説配分(35%/30%/12%/10%/7%/6%)である
- 表4-1は21区分のため、以下は代替値を使用: ニュージーランドは豪州、メキシコ・イスラエル・トルコ・湾岸6か国は「その他」、オランダ・ベルギー・スイス・北欧4か国は欧州5か国(英・独・仏・伊・西)の回答数加重平均(13.9泊)

## ロケーション

東京都が発表した地域別の訪問調査の結果をもとに仮説的に作成。

### 算出方法

- 出典: 東京都「令和6年 国・地域別外国人旅行者行動特性調査」図表18「訪問した場所(複数回答)」全体(n=14,091)
- 平均滞在日数: 同調査 図表26「東京滞在中の平均泊数」5.6泊 → **6.6日** (5.6泊 + 1)

原典は「区」ではなく「渋谷」「浅草」などの**地区名**単位であり、かつ**旅行全体**での訪問率(複数回答)であるため、次の2段階で変換した。

**1. 地区 → 区への割当**

行政区界に従って各地区を区に割り当てた。複数区にまたがる地区は按分している。

| 調査上の地区 | 訪問率 | 割当先 |
| --- | ---: | --- |
| 東京駅周辺・丸の内・日本橋 | 51.1% | 千代田区 60% / 中央区 40% (日本橋は中央区) |
| 原宿・表参道・青山 | 33.1% | 渋谷区 70% / 港区 30% (青山は港区) |
| 品川 | 15.9% | 港区 70% / 品川区 30% (品川駅は港区港南・高輪) |
| お台場・東京湾 | 14.5% | 港区 55% / 江東区 45% (台場は港区、青海・有明は江東区) |

同一区に複数地区が該当する場合は、独立を仮定して和集合を取る: P(区を訪問) = 1 - Π(1 - p<sub>地区</sub>)

なお、吉祥寺・三鷹(3.5%)、八王子・高尾山(3.1%)、立川(2.2%)、伊豆諸島・小笠原諸島(1.1%)、奥多摩(1.0%)、青梅・御岳山(0.9%)は23区外のため除外した。

**2. 旅行全体 → 1日あたりへの変換**

各日を独立試行と仮定し、旅行全体の訪問率を「6.6日間で少なくとも1回訪問する確率」とみなして日次確率に逆算した。

p<sub>旅行</sub> = 1 - (1 - p<sub>日</sub>)<sup>6.6</sup> → **p<sub>日</sub> = 1 - (1 - p<sub>旅行</sub>)<sup>1/6.6</sup>**

**3. 調査対象外の区の補間**

図表18の選択肢には以下の11区に対応する地区が存在せず、実際の訪問は「その他(4.4%)」に埋没している。各区の集客要素をもとに旅行全体訪問率を推計した(下表 ※印)。

### 注記・前提

- 1日あたりの延べ訪問区数は **0.94区/日** となる。原典の訪問地区数が1旅行あたり約5地区(6.6日間)であることに由来し、日帰り旅行・休息日・区外の宿泊などを含むため1を下回る。実態より保守的な可能性があり、体感に合わせる場合は全区に一律の係数を乗じて調整する
- 実証実験対象6区(新宿・中央・台東・千代田・港・渋谷)のいずれかに滞在する確率は、独立を仮定すると1日あたり **59.3%** となる
- 同一区内の複数地区の和集合、および日次の独立性はいずれも独立仮定に基づく。実際には「渋谷に行く人は原宿にも行く」のような正の相関があるため、区単位の訪問率はやや高めに出ている可能性がある
- 墨田区の6.6%は東京スカイツリーの集客力に対して低く見えるが、原典の「墨田・両国」の値をそのまま採用している。隣接する浅草(台東区)と一体で回答された可能性がある
- 原典は国・地域別の上位10か所も公表しており(韓国は渋谷63.9%、台湾は浅草46.4%が最多など)、国籍別の滞在確率を作ることも可能。本表は全体値のみを用いている
- 本表は令和6年(2024年)調査であり、国籍分布の基準期間(2026年1月～4月)とは年次が異なる
