# XBCOM株式会社

XBCOM株式会社は、東京に本社を置く通信会社であり、訪日インバウンド旅行者および日本発アウトバウンド旅行者に対して、eSIMによるモバイルデータ通信サービスを提供している。訪日外国人旅行者の利用者数は年間およそ50万人にのぼる。


## eSIMサービス
XBCOMはモバイルアプリ「XB eSIM」を運営しており、利用者はこのアプリ経由でeSIMサービスを申請・購入し、このサービスは基本的に実利用日数ベースの課金体系である。XB eSIMは20言語以上をサポートしており、多様な支払手段で利用できるようになっている。サービスの使いやすさと割安の料金プランにより、海外の利用者の中で人気が高く、リピーターも多い状況である。


## インバウンド利用者数の拡大プラン
訪日旅行ブームの追い風を受け、さらなる利用者数の拡大を図るため、XBCOMは訪日外国人旅行者を対象としたクーポンプラットフォームの構築を進めており、本番開発の前に実証実験を実施する。飲食、小売、娯楽、宿泊、交通などの各店舗から幅広いクーポンを集め、XB eSIMアプリ上でベネフィットとして利用者に提供することで、新規利用者の獲得とリピート率の向上を狙う。
